# susamn/homebrew-tap

The single Homebrew tap for everything I publish. One tap, one file per tool.

```bash
brew install susamn/tap/<tool>
```

`susamn/tap` is this repository — Homebrew expands it to `susamn/homebrew-tap`.

## Tools

| Tool | Install | Kind |
|---|---|---|
| [mpdtui](https://github.com/susamn/mpdtui) | `brew install susamn/tap/mpdtui` | cask |
| [lshwtui](https://github.com/susamn/lshwtui) | `brew install susamn/tap/lshwtui` | cask |
| [uff](https://github.com/susamn/uff) | `brew install susamn/tap/uff` | formula |

## Layout

- `Casks/` — prebuilt binaries. **Generated by GoReleaser** on each tag in the
  tool's own repo. Never hand-edit one; the next release overwrites it. Fix the
  source repo's `.goreleaser.yaml` and cut a patch release instead.
- `Formula/` — hand-maintained: scripts, and anything built from source.

## How a release reaches this tap

```
susamn/<tool>          tag v1.2.3 pushed
   └─ .goreleaser.yaml ──► CI: test → build → GitHub release
                              └──► commits Casks/<tool>.rb here
                                   (needs HOMEBREW_TAP_TOKEN on the source repo)
```

`HOMEBREW_TAP_TOKEN` is a fine-grained PAT scoped to this repository with
Contents: read and write. Actions' default `GITHUB_TOKEN` cannot write to
another repository, so without it a release publishes fine and silently leaves
this tap stale.

## Deprecated taps

`susamn/homebrew-mpdtui` is retired. Move over with:

```bash
brew uninstall mpdtui && brew untap susamn/mpdtui
brew install susamn/tap/mpdtui
```
